# @shop/util

Des types et fonctions sans état, utilisables partout : pour l'instant `ControlsOf<T>`, qui décrit
les contrôles d'un formulaire réactif typé à partir d'un modèle (`FormGroup<ControlsOf<Dossier>>`).
Elle ne dépend que d'Angular. Aucune étape du lab ne l'impose : voir la section « Pour aller plus
loin » du [README du lab](../../../README.md).

Tests : `npx ng test @shop/util --watch=false`.
