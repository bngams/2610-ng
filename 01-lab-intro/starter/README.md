# Lab Intro — point de départ du parcours Init

Le projet vide du catalogue de formations : les données (`src/app/data/formations.data.ts`), le
modèle (`src/app/models/formation.ts`) et un peu de CSS. Le reste, vous l'écrivez en suivant le
guide, à partir de l'étape [I1 — La liste](../INIT/I1-LISTE.md).

```bash
npm install          # Node 22.22 ou 24.15 minimum
npm start            # ng serve sur http://localhost:4200
npm test             # 1 test, vert dès le départ
```
