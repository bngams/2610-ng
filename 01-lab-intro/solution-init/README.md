# Lab Intro — solution du parcours Init

Le catalogue terminé après les étapes I1 à I4 : la liste, la carte avec `input()` et `output()`,
le service injecté, et le panier en `signal()` avec son total en `computed()`. À ne regarder
qu'en cas de blocage ; le guide est dans [`INIT/`](../INIT/).

```bash
npm install          # Node 22.22 ou 24.15 minimum
npm start            # ng serve sur http://localhost:4200
npm test             # 2 tests, dont un qui clique sur « S'inscrire » et vérifie le panier
```
