# 02 — Les formulaires en Angular 22

La synthèse du jour 2 sur les formulaires : les trois familles (template-driven, Reactive Forms, Signal Forms),
qui détient la valeur dans chacune, `FormGroup` / `FormArray` / typed forms, Signal Forms et son formulaire en
plusieurs étapes, puis un formulaire dynamique construit depuis une description JSON, et comment choisir.

- 📄 **La page à garder** : [index.html](index.html), imprimable.
  En ligne : **https://bngams.github.io/2610-ng/02-intro-forms/**

Pas de projet à lancer ici : chaque extrait de la page a été compilé (`ng build`) et vérifié dans le navigateur
sur un projet Angular 22 de test, qui n'est pas livré.
